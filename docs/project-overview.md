# Project Overview

## Overview

Banking Operations Intelligence is an AI-powered platform intended to monitor banking products and operational metrics, identify unusual behavior, investigate potential causes, and support operational decision-making.

## Core Intelligence Loop

The long-term system will follow:

Detect → Investigate → Explain → Recommend → Act → Verify → Learn

## Initial Product

The first implementation focuses on the Credit Card product.

## Initial Development Approach

The project follows a top-down approach:

1. Understand the business requirements
2. Define Product Health KPIs
3. Identify required data
4. Design the logical data model
5. Design the OLAP/analytical layer
6. Create analytical views
7. Build the Power BI Product Health view
8. Introduce anomaly detection
9. Build AI-powered investigation
10. Add recommendations, actions, verification, and incident memory

## Current Phase

The current phase is focused on the data and analytics foundation required before implementing the intelligence layer.
